SANE protocol log

Talks to saned directly

SaneTwain.ds 1.37 is a closed 2013 binary, so it can't be edited. The new app speaks the same SANE network protocol on port 6566 and reads your existing sanetwain.ini for host, user and device, so nothing on the server changes.

ControlCenter3 buttons

File, Image, OCR and E-mail each keep their own folder, file name, type, resolution and scan type. That matches how ControlCenter3 configures its scan buttons, but it works over the network through saned.

Saves when the scan ends

No Save dialog. The file is written the moment you finish. Missing folders are created, and taken names get " (2)" added. Multi-page PDF, TIFF and searchable OCR PDF are all supported.

App settings

These apply to every scan button. Stored in C:\Users\TSL\sanetwain.ini, so SaneTwain keeps working too.
